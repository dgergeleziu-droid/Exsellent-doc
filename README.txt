SA — статическая версия сайта (Republic of Exsellent)
======================================================

Содержимое:
  index.html          — главная страница
  editor/index.html   — редактор документов
  assets/             — скрипты и стили
  img/                — декоративные изображения
  favicon.ico

Как открыть:
Файлы используют абсолютные пути (/assets/...), поэтому их нужно открыть
через любой локальный веб-сервер, а не двойным щелчком по index.html.
Например, в этой папке выполните одну из команд:

  npx serve .
  python3 -m http.server 8000

и откройте в браузере http://localhost:3000 (serve) или http://localhost:8000.

Эту папку также можно загрузить как есть на любой статический хостинг
(Netlify Drop, GitHub Pages с корнем домена и т. п.).
Шрифты подгружаются из Google Fonts, поэтому нужен интернет.
